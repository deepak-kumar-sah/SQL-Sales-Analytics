# SQL Sales Analytics

A beginner-to-interview-level **SQL Sales Analytics project** built with MySQL.  
This project analyzes sales transactions using filtering, aggregation, grouping, subqueries, CASE statements, date functions, and window functions.

## Project Objective

The objective is to practice SQL on a realistic sales dataset and answer common **Data Analyst interview and business-analysis questions**, including:

- Revenue and order analysis
- Product and category performance
- City-wise sales performance
- Average Order Value (AOV)
- Revenue contribution percentages
- Top-performing products and cities
- Orders above average revenue
- Second-highest values
- Ranking with window functions
- Running totals
- Customer and product analysis

## Example Queries

### 1. Total Revenue

```sql
SELECT SUM(revenue) AS total_revenue
FROM sales;
```

### 2. Revenue by City

```sql
SELECT city, SUM(revenue) AS total_revenue
FROM sales
GROUP BY city
ORDER BY total_revenue DESC;
```

### 3. Top 3 Products by Revenue

```sql
SELECT
    product,
    SUM(revenue) AS total_revenue
FROM sales
GROUP BY product
ORDER BY total_revenue DESC
LIMIT 3;
```

### 4. Average Order Value

```sql
SELECT
    SUM(revenue) / COUNT(DISTINCT order_id) AS AOV
FROM sales;
```

### 5. Highest Revenue Order in Each City

```sql
SELECT city, product, revenue
FROM (
    SELECT
        city,
        product,
        revenue,
        RANK() OVER (
            PARTITION BY city
            ORDER BY revenue DESC
        ) AS rnk
    FROM sales
) AS ranked_sales
WHERE rnk = 1;
```

### 6. Cities with Both Categories

```sql
SELECT city
FROM sales
GROUP BY city
HAVING COUNT(DISTINCT category) = 2;
```

## How to Run

### Step 1 — Install MySQL

Install MySQL Server and MySQL Workbench if they are not already installed.

### Step 2 — Open the SQL file

Open:

```text
dataset/sales.sql
```

in MySQL Workbench or another MySQL-compatible SQL editor.

### Step 3 — Execute the script

Run the script. It will:

1. Create the `sales_analytics` database
2. Create the `sales` table
3. Insert the sample data
4. Run the complete SQL analysis

### Step 4 — Practice the queries

The queries are numbered from **Q1 to Q80** so they can also be used for SQL interview practice.
